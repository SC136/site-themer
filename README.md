# Site Themer

Browser extension that themes websites (currently WhatsApp Web) with true AMOLED black and other dark themes.

- `site-themer/` – the extension (see its README)
- `docs/` – landing page, served by GitHub Pages
- `package-extension.ps1` – rebuilds `docs/downloads/site-themer.zip`

After changing the extension, run `powershell -File package-extension.ps1` and commit the new zip.
