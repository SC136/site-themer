Setup

Get it running.

Install once, then switch themes from the extension popup.

Download started. Unzip the file, then follow the steps below.

  1. Download and unzip

    Get the ZIP and extract it. Keep the extracted folder somewhere permanent so the browser can keep loading it.

  2. Load the extension

    Open your browser’s extensions page, enable Developer mode, and click Load unpacked. Select the folder containing manifest.json.

    chrome://extensions

  3. Pick your dark theme

    Turn on the site’s own dark mode, then refresh. Pin Site Themer from your browser’s extensions menu and choose a preset for either site.

    Where to find dark mode

    WhatsApp Web · Settings → Chat → Theme → Dark
    YouTube · Profile → Appearance → Dark theme

Help

Questions?

Why didn’t the theme change?

Enable the site’s built-in dark mode and refresh the tab. Check that Site Themer is enabled for that site in the popup.

What if the manifest is missing?

In Load unpacked, choose the extracted folder that directly contains manifest.json.

What permissions does it need?

Site Themer uses browser storage to remember your settings and applies its theme on WhatsApp Web and YouTube.

Does it work in Firefox or Safari?

The current release supports Chrome, Edge, and Brave.

Where can I report a bug?

Open a GitHub issue with the site, preset, and a description of what looks wrong.
