site themer

version: 1.4.0 · chromium only · free · no tracking

dark mode on whatsapp web and youtube is grey. mine isn't anymore. this is a small browser extension that turns them into proper amoled black, with a few themes and per-site options so it feels like yours.

supported sites: whatsapp web youtube

tldr; download it, unzip it, then follow the 6 install steps below. it takes about a minute and there's nothing to sign up for.

how to install

it isn't in a web store yet, so you add it by hand. it's safe, and you only do this once. follow the 6 steps below in order.

  1. 1

    download and unzip

    click download. then unzip the file: right-click it and choose extract all (on mac, double-click it).

    important: keep the unzipped site-themer folder somewhere permanent, like documents. if you delete it, the extension stops working.

  2. 2

    open your browser's extensions page

    pick your browser, then click copy.

    chrome://extensions

    then press ctrl + t to open a new tab, ctrl + v to paste, and enter.

    browsers don't let websites open this page for you, so it has to be pasted into the address bar.

  3. 3

    turn on developer mode

    find the developer mode switch and turn it on. it's in the top-right corner (in edge it's in the left sidebar). three new buttons appear.

  4. 4

    click "load unpacked"

    click load unpacked, then pick the site-themer folder you unzipped in step 1.

    pick the folder that directly contains manifest.json. if you see "manifest file is missing", you're one folder too high or too low.

  5. 5

    switch the site to dark mode

    whatsapp: open web.whatsapp.com and go to settings → chat → theme → dark.

    youtube: open youtube.com, click your profile picture, then appearance → dark theme.

    the themes only work on top of each site's own dark mode. refresh the page once afterwards.

  6. 6

    pick your theme

    click the puzzle-piece icon in your browser toolbar, pin site themer, then click it to choose a theme. changes show up right away.

that's it. if something doesn't look right, check the faq.

faq

nothing changed after installing

reload the whatsapp or youtube tab and make sure the site's own theme is set to dark.

"manifest file is missing or unreadable"

you picked the wrong folder. select the one that directly contains manifest.json.

some parts turned grey after a site update

whatsapp and youtube change their pages often. open an issue and i'll update the theme.

is it safe?

the code is open source on github. it's css plus a small settings popup, and it only asks for storage permission to remember your theme.

firefox or safari?

not supported yet.

found something broken?

no spam, no noise. just tell me what stayed grey and i'll fix it.

open an issue

not affiliated with whatsapp, meta, youtube or google. site themer only changes colors in your own browser.
