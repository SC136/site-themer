how to install

it isn't in a web store yet, so you load it manually. safe, and takes about a minute.

  1. download and unzip. right-click the zip and choose extract all (mac: double-click). keep the site-themer folder somewhere permanent. deleting it removes the extension.
  2. open the extensions page. type chrome://extensions in the address bar (edge://extensions for edge, brave://extensions for brave).
  3. turn on developer mode. it's a toggle in the top-right corner (left sidebar in edge).
  4. click "load unpacked" and select the site-themer folder, the one that contains manifest.json.
  5. turn on whatsapp's dark mode. on web.whatsapp.com go to settings → chat → theme → dark.
  6. choose a theme. click the puzzle-piece icon, pin site themer, and open it to pick a theme.

    7. faq

    nothing changed after installing

    reload the whatsapp tab and make sure whatsapp's own theme is set to dark.

    "manifest file is missing or unreadable"

    you picked the wrong folder. select the one that directly contains manifest.json.

    some parts turned grey after a whatsapp update

    whatsapp changes its page often. open an issue and i'll update the theme.

    the code is open source on github. it's css plus a small settings popup, and it only asks for storage permission to remember your theme.

    not supported yet.
